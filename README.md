# Homebrew tap for Warden

```bash
brew install abhishek-mallick/tap/warden
```

Installs `warden` (the gateway and CLI) and `warden-mcp` (the MCP server).

`Formula/warden.rb` is generated by Warden's release pipeline from the checksums of the
artefacts that actually shipped. Do not edit it by hand: the next release overwrites it.
